# NPC月内活动0.3.8：真实突破材料检查

## 代码4与错误的1/1

原生突破行动的代码4表示选中的天材地宝soleID在人物背包里不存在。GetFastRarity会先创建所需长度的数组，没找到物品时保留空字符串。旧模组错误地按数组长度显示“1/1”，实际上空槽不代表已有物品，导致人物长期待命。

0.3.8逐一检查原生选择中的实际物品及数量：空值、空白和失效soleID不计数，同一物品不能跨两类材料超额使用。只有真实材料数量齐全，才创建并检查原生突破行动。缺少时显示实际数量和具体缺项，继续沿用现有采购、附近NPC索取及资金不足时的委托筹款。天材地宝缺材目录改为目标大境界，与原生GetFastRarity一致。

这些获取途径暂未覆盖所有天材地宝；如果没有有效现货、附近持有人或已适配来源，会明确待命，不生成虚构材料或强行突破。能正确识别缺材，并不等于已经实现所有材料来源的自动收集。

## 米古修为是否上涨

0.3.7实测日志显示，米古有1600→1744、1744→1864的真实修炼，nativeDays均为1；随后原始和动态修为均达到2346，已到炼气后期通往筑基的门槛。此后不再增长是正常瓶颈，需要筹备筑基，不能把进度条不动当作前面的修炼完全无效。

0.3.7还记录了柏夜春、常青亦与鲁忆远的小阶段突破成功及每次成功后扣除一颗丹药。本版保留一天修炼、突破后扣药和失败保药规则。旧版柏夜春的历史损失仍不追补。
